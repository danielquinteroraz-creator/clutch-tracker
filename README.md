# CLUTCH

Tracker móvil de Valorant con datos ficticios. La app está en `www/` y solo usa HTML, CSS y JavaScript.

Para probarla por HTTP, ejecuta `python -m http.server 8080 --directory www` y abre `http://localhost:8080`. Busca `UmbraByte#404` en LATAM o escribe tu propio `Nombre#TAG` para generar un perfil reproducible.

El historial, los favoritos y las preferencias se guardan en el dispositivo. Los gráficos, emblemas e iconos son originales. La interfaz usa fuentes del sistema y funciona con los archivos locales del WebView.
