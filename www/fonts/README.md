# Fuentes

- **Chakra Petch** (500, 600, 700) — títulos y números. Cadson Demak, SIL Open Font License 1.1.
- **Inter Tight** (400, 500, 600, 700) — texto. Rasmus Andersson, SIL Open Font License 1.1.

Archivos woff2 (subconjunto latino) obtenidos de los paquetes npm `@fontsource/chakra-petch@5.2.5` y `@fontsource/inter-tight@5.2.5`. Se cargan localmente desde `css/app.css`, sin conexión a internet.
